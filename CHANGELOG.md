# Changelog

All notable changes to BioDepot Workbench are documented here.

## 0.1.0 - 2026-08-26

Initial public platform release:

- HTTP API, browser workbench, and MCP server;
- durable conversation and workflow-run state;
- execution-location, review, preflight, and bundle contracts;
- persistent module registry, graph projection, and typed graph search;
- deterministic planner behavior with optional model fallback;
- bounded nf-core metadata harvest, source decomposition, schema mapping, and
  bundle rendering;
- public test fixtures, release measurements, and privacy/security scrub.

The release intentionally excludes deployment and host configuration, private
data and operational records, and non-public execution integrations.
